# agent-skills

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語**

**Claude Code**・**Codex**・**ZCode** など、スキルを読み込める AI コーディングエージェント向けの実用的な **Agent Skills**（`SKILL.md`）4 本です。高速なブラウザ自動操作ループ、別モデルによるクロスレビュー、書き始める前の思考整理、小紅書／WeChat 記事リーダーをそろえています。

| Skill | ひとことで | 起動方法 |
|---|---|---|
| [jev-browser-skill](#jev-browser-skill複数ステップのブラウザ操作を-1-回の呼び出しで) | 複数ステップのブラウザ操作を 1 回のスクリプト呼び出しで完了。エージェントの逐次操作より約 3 倍速い | `/jev-browser-skill` |
| [cross-review](#cross-review別モデルが各工程をレビュー) | 別の AI（agy / Codex / Claude）が各工程の成果物を読み取り専用でレビュー | 「双审」と言う、または `/cross-review` |
| [prewrite](#prewriteまとまらない考えを執筆マップに) | 散らかったアイデアを、すぐ書き始められる地図に整理 | 自動、または `/prewrite` |
| [read-article](#read-article小紅書--wechat-公式アカウント記事を-markdown-に) | 小紅書（RED）のノート、WeChat 公式アカウント記事 → Markdown | リンクを貼ると自動 |

> スキル本文は中国語で書かれていますが、エージェントはどの言語でも問題なく従います。エージェントへの指示は日本語で構いません。

## インストール

[`skills`](https://www.npmjs.com/package/skills) CLI を使います：

```bash
npx skills add sageri/agent-skills -s jev-browser-skill -g
```

`jev-browser-skill` を任意のスキル名に置き換えてください。`-s '*'` で 4 本すべて入ります。`-g` はユーザー単位のインストールで、外すと現在のプロジェクトに入ります。

## jev-browser-skill：複数ステップのブラウザ操作を 1 回の呼び出しで

エージェントにブラウザを逐次操作させると、クリックのたびにメインモデルが 1 往復します。大きなページのスナップショットを読んで、考えて、操作する、の繰り返しです。このスキルはサブタスク全体を小さなループスクリプトに任せます。各ステップで **[TypeSafe Jev](https://docs.typesafe.ai)**（数百ミリ秒で型付きの選択を返す高速判断モデル）にどの要素を操作するかを尋ね、**[Tencent BrowserSkill](https://github.com/Tencent/BrowserSkill)**（`bsk`）経由で、ログイン済みの実際のブラウザ上で実行します。

```bash
node <skillディレクトリ>/scripts/loop.mjs --url https://transit.yahoo.co.jp/ \
  --goal "乗換案内で、出発に from、到着に to を入力し、日時を 2026年9月27日 9時00分 出発に設定して検索する" \
  --values from=川崎,to=大阪 \
  --expect-url 'search/result.*d=27&hh=09&m1=0&m2=0'
```

ゴールはどの言語の自然文でも書けます。普段は自分で打つ必要はありません。`/jev-browser-skill <タスク>` と入力すれば、エージェントがこのコマンドを組み立てます。

実サイトでの計測（同じマシン・同じタスク・エンドツーエンドの所要時間。少数サンプルで、正式なベンチマークではありません）：

| タスク | エージェントが逐次操作 | jev-browser-skill |
|---|---|---|
| Yahoo!ニュース：主要トピックス上位 3 件 | メインモデル 5 回呼び出し、68 秒 | 1 回呼び出し、6〜12 秒 |
| Yahoo!路線情報：日時指定で乗換検索 | メインモデル 7 回呼び出し、54 秒 | 1 回呼び出し、約 17 秒 |
| ヨドバシ.com：直近の購入 3 件 | メインモデル 8 回呼び出し、53 秒 | 1 回呼び出し、約 19 秒 |

**安全性はプロンプトではなくコードで担保。** すべてのガードは、ページ内容がお使いの PC から出る前に実行されます：

- 銀行、医療、ログインページ、社内ネットワーク、パスワード欄が見えているページは、モデルに送る前に停止します。
- `--values` で渡した値は Jev に送られません。Jev が見るのは項目名だけです。
- 取り消せないクリック（購入・送信・削除・確定など）は実行前に止まって確認を求めます。機密項目（カード番号・暗証番号など）は入力しません。
- 完了判定は、指定した `--expect-url` / `--expect-text` のアサーションで行います。モデルに「終わった？」とは聞きません。

ループが最後までやり切れない場合は、型付きのステータス（`confirm_required`、`text_value_unavailable`、`stuck`、`blocked` など）付きで**差し戻し**ます。ブラウザセッションは開いたままなので、エージェントやあなた自身が `--resume` で止まった地点から再開できます。

**前提条件：**[BrowserSkill](https://github.com/Tencent/BrowserSkill)（`bsk` CLI＋ブラウザ拡張＋`browser-skill` スキル）、Node.js 18 以上、環境変数 `TYPESAFE_API_KEY`。npm 依存はありません。ページのテキストは TypeSafe API に送信されます。詳しくは[プライバシー](skills/jev-browser-skill/references/privacy.md)を参照してください。[browser-use/jev-ultrafast](https://github.com/browser-use/jev-ultrafast) の移植です。

## cross-review：別モデルが各工程をレビュー

作業はメインのエージェントが行い、**別の AI CLI が読み取り専用でレビュー**します。指摘の一つひとつに「採用／却下＋理由」を明記するので、単一モデルの見落としを拾えて、しかもレビュアーはファイルに触れられません。

- **コード作業**：5 段階のパイプライン（要件 → 設計 → 仕様 → 実装＋テスト → 検証）。各段階の後にレビューゲートがあり、仕様はあなた自身が承認します。
- **コード以外の成果物**（翻訳・レポート・スライド）：完成品に 1 回のレビューゲート。
- **既存の成果物**：設計書、diff、テスト結果を指定して、それだけをレビュー。
- レビュアーは各ゲートに 1 名。既定は `agy`（Antigravity CLI）で、`codex` や `claude` を指名できます。CLI の呼び出しに失敗したときは自動で次に切り替えます。
- レビュー依頼、レビュー原文、判定、トークン使用量はすべて `.cross-review/<task-id>/` に保存され、どの判断も後から追えます。

**前提条件：**`agy`・`codex`・`claude` のいずれか 1 つ以上の CLI がインストール済みでログイン済みであること。

## prewrite：まとまらない考えを執筆マップに

最初の一文が書けないとき、prewrite はまず**どこで詰まっているか**を見極め、代筆ではなく地図を渡します：

- **書き出せない** → まず頭の中を全部吐き出す。書いている間は静かに見守り、終わったら要点を取り出します。
- **素材が多すぎて軸が見えない** → KJ 法でまとめるか、4 層の蒸留で一文まで絞り込みます。
- **主張はあるのにうまく説明できない** → 3 つの関門：主張を研ぐ、論理の連鎖を組む、反論に耐えるか試す。

質問は一度に 1 つだけ。見出しはすべて「反対する人がいる」判断文で書きます。頼まない限り本文は書きません。既存の下書きの推敲には向きません。

## read-article：小紅書 / WeChat 公式アカウント記事を Markdown に

**小紅書（RED）**のノートや **WeChat 公式アカウント**の記事リンクを貼ると、タイトル・著者・日時・本文・画像／動画 URL を含むきれいな Markdown になり、エージェントがそのまま読んだり要約したりできます。ログイン用 Cookie は不要です。両プラットフォームともクラウドの IP を遮断するため、お使いの PC 上で実行します。

```bash
pip install requests beautifulsoup4 curl_cffi markdownify
```

小紅書のリンクは、アプリから共有した完全なリンク（`xsec_token` 付き）が必要です。任意で Cookie（環境変数 `XHS_COOKIE` または `~/.xhs-cookie.txt`）を設定すると取得が安定します。

> **免責事項：**このスキルはモバイルクライアントとブラウザのフィンガープリントを模倣してページを取得するため、各プラットフォームの利用規約に抵触する可能性があります。個人の学習目的に限り、利用は自己責任でお願いします。
