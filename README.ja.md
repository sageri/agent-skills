# Agent Skills 🧩

> **AI コーディングアシスタントを「使える」から「頼れる」へ。**
> すぐ使える 4 本の Skill：ブラウザ自動操作、別モデルによるクロスレビュー、書く前の思考整理、小紅書／WeChat 記事の取得。
> Claude Code · Codex · ZCode · そして Skill を読み込めるあらゆる AI に。

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**　　⭐ **役に立ったら Star をいただけると、開発の何よりの励みになります。**

## ✨ なぜこの Skill なのか

こんな経験、ありませんか：

- 🤖 AI にサイトを操作させたら、1 回クリックして考え込み、またクリック……7 回のクリックに 1 分かかった
- 👀 自分で書いたコード、どこかおかしい気がするのに見つけられない
- ✍️ タイトルに 3 時間悩んで、本文はまだ白紙
- 📱 小紅書のリンクを AI に渡したのに、中身を読んでもらえない

この 4 本の Skill は、まさにそんな瞬間のためのものです。

> スキル本文は中国語で書かれていますが、エージェントは問題なく従います。エージェントへの指示は日本語で大丈夫です。

## 📦 インストール

```bash
npx skills add sageri/agent-skills -s jev-browser-skill -g
```

`jev-browser-skill` を任意のスキル名に置き換えてください。`-s '*'` で 4 本すべてインストールできます。`-g` はユーザー単位のインストールで、外すと現在のプロジェクトに入ります。

<a id="jev-browser-skill"></a>

## 🖱️ jev-browser-skill：ブラウザ自動操作を、**もう途切れさせない**

エージェントがブラウザを逐次操作すると、1 回クリックするたびにメインモデルが 1 往復します。大きなページのスナップショットを読み、考え、操作する、の繰り返しです。

この Skill はサブタスク全体を小さなループスクリプトに任せます。各ステップで [TypeSafe Jev](https://docs.typesafe.ai)（数百ミリ秒で型付きの選択を返す高速判断モデル）にどの要素を操作するかを尋ね、[Tencent BrowserSkill](https://github.com/Tencent/BrowserSkill)（bsk）経由で**ログイン済みの実際のブラウザ**上で実行します。

```bash
node <skillディレクトリ>/scripts/loop.mjs \
  --url https://transit.yahoo.co.jp/ \
  --goal "乗換案内で、出発に from、到着に to を入力し、日時を 2026年9月27日 9時00分 出発に設定して検索する" \
  --values from=川崎,to=大阪 \
  --expect-url 'search/result.*d=27&hh=09&m1=0&m2=0'
```

> ゴールはどの言語の自然文でも書けます。普段は自分で打つ必要はありません。`/jev-browser-skill <タスク>` と入力すれば、エージェントがこのコマンドを書いてくれます。

### ⚡ 実サイトでの計測

*同じマシン・同じタスク・エンドツーエンドの所要時間（少数サンプルで、正式なベンチマークではありません）：*

| タスク | エージェントが逐次操作 | jev-browser-skill | 高速化 |
|---|---|---|---|
| Yahoo!ニュース：主要トピックス上位 3 件 | 5 回呼び出し · 68 秒 | 1 回呼び出し · 6〜12 秒 | **🚀 ~6–11×** |
| Yahoo!路線情報：日時指定で乗換検索 | 7 回呼び出し · 54 秒 | 1 回呼び出し · ~17 秒 | **🚀 ~3×** |
| ヨドバシ.com：直近の購入 3 件 | 8 回呼び出し · 53 秒 | 1 回呼び出し · ~19 秒 | **🚀 ~3×** |

### 🔒 安全性はプロンプトではなく、コードで担保

すべてのガードは、ページ内容が**お使いの PC から出る前に**実行されます：

- 🚫 銀行、医療、ログインページ、社内ネットワーク、パスワード欄が見えているページは、モデルに送る前に止めます
- 🚫 `--values` で渡した値は Jev に送りません。Jev が見るのは項目名だけです
- 🚫 取り消せないクリック（購入・送信・削除・確定など）は、実行前に止まってあなたに確認します
- 🚫 機密項目（カード番号・暗証番号など）は入力しません
- ✅ 完了したかどうかは、指定した `--expect-url` / `--expect-text` のアサーションで判定します。モデルに「終わった？」とは聞きません

ループが最後までやり切れないときは、**型付きのステータス**（`confirm_required` / `text_value_unavailable` / `stuck` / `blocked` …）付きで差し戻します。ブラウザセッションは開いたままなので、エージェントやあなた自身が `--resume` で止まった地点から続けられます。

**前提条件：** [BrowserSkill](https://github.com/Tencent/BrowserSkill)（bsk CLI＋ブラウザ拡張＋browser-skill スキル）、Node.js 18 以上、環境変数 `TYPESAFE_API_KEY`。npm 依存はゼロです。ページのテキストは TypeSafe API に送信されます。詳しくは[プライバシー](skills/jev-browser-skill/references/privacy.md)を参照してください。[browser-use/jev-ultrafast](https://github.com/browser-use/jev-ultrafast) の移植です。

<a id="cross-review"></a>

## 🛡️ cross-review：別の AI が、**各工程を読み取り専用でレビュー**

> 自分の盲点は、自分では見つけられない。

作業はメインのエージェントが行い、別の AI CLI が読み取り専用でレビューします。指摘の一つひとつに「**採用／却下＋理由**」を明記します。単一のモデルが見落とした問題を拾えて、しかもレビュアーはあなたのファイルに触れられません。

- 🧱 **コード作業**：5 段階のパイプライン（要件 → 設計 → 仕様 → 実装＋テスト → 検証）。各段階の後にレビューゲートがあり、仕様はあなた自身が承認します
- 📝 **コード以外の成果物**（翻訳・レポート・スライド）：完成品に 1 回のレビューゲート
- 📂 **既存の成果物**：設計書、diff、テスト結果を指定して、それだけをレビュー
- 👥 **各ゲートのレビュアーは 1 名**：既定は `agy`（Antigravity CLI）で、`codex` や `claude` を指名できます。CLI の呼び出しに失敗したら自動で次に切り替えます
- 📁 レビュー依頼、レビュー原文、判定、トークン使用量はすべて `.cross-review/` に保存され、どの判断も後から追えます

**前提条件：** `agy`・`codex`・`claude` のいずれか 1 つ以上の CLI がインストール済みでログイン済みであること。

<a id="prewrite"></a>

## 🗺️ prewrite：まとまらない考えを、**一枚の地図に**

> 最初の一文が書けない？まだ書かなくていい。

prewrite はまず、あなたがどこで詰まっているかを見極め、代筆の原稿ではなく**一枚の地図**を渡します：

- 🧱 **書き出せない** → まず全部吐き出す：書いている間は静かに見守り、書き終えたら要点を取り出します
- 🌪️ **素材が多すぎて軸が見えない** → KJ 法でまとめるか、4 層の蒸留で一文まで絞り込みます
- 🎯 **主張はあるのに説明できない** → 3 つの関門：主張を研ぐ、論理の連鎖を組む、反論に耐えるか試す

✨ 質問は一度に 1 つだけ。見出しはすべて「**反対する人がいる**」判断文で書きます。はっきり頼まない限り、**本文は書きません**。

> ℹ️ 既存の下書きの推敲には向きません。

<a id="read-article"></a>

## 📰 read-article：小紅書 / WeChat → Markdown

> リンクを貼れば、きれいな Markdown が手に入る。

タイトル、著者、日時、本文、画像／動画の直リンクが取得でき、エージェントがそのまま読んだり要約したりします。

- 🍪 ログイン用 Cookie は不要
- 🏠 両プラットフォームともクラウドの IP を遮断するため、**お使いの PC 上で実行**します
- 🐍 依存は 4 つだけ：`requests`、`beautifulsoup4`、`curl_cffi`、`markdownify`

```bash
pip install requests beautifulsoup4 curl_cffi markdownify
```

> 📌 小紅書のリンクは、アプリから共有した完全なリンク（`xsec_token` 付き）が必要です。任意で Cookie（環境変数 `XHS_COOKIE` または `~/.xhs-cookie.txt`）を設定すると、取得が安定します。

⚠️ **免責事項：** この Skill はモバイルクライアントとブラウザのフィンガープリントを模倣してページを取得するため、各プラットフォームの利用規約に抵触する可能性があります。個人の学習目的に限り、利用は自己責任でお願いします。
