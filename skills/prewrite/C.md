# C：有观点但说不清，过三关

顺序不能换。观点不够有力，论证做得再严密也没用。

## 第一关：锋度检验

观点没说服力，通常不是想法不好，是表达太保守——"可能""也许""在某些情况下"塞进去是为了不被反驳，结果观点变成了人人同意的废话。

这一关交三样，缺一样都不算过：**四问的回答**、**一个强化版本**、**一句追问**。

**一、对用户的核心论点回答四问。**

1. 这是"有人会反对的主张"，还是"谁都默认同意的事实描述"？是后者，指出它在哪里失去了态度。
2. 有没有说出一件"读者没意识到、但听完会觉得确实"的事？还是只把读者已经知道的换了种说法？
3. 这个观点的底层假设是什么？现实里有没有能推翻这个假设的反例？
4. 站到持相反立场的人的位置上，他最可能用哪一句话来反驳？

第 4 问不是为了让用户放弃观点，是逼他想清楚有人不同意时怎么回应——想不清楚，论证就没有根基。

**二、给一个强化版本。** 不改核心意思，更有态度、更敢于被反驳。

答完四问最容易觉得这一关已经做完了，于是直接抛个问题回给用户——那样这一关就白过了。四问只是诊断，强化版本才是交付物，必须给出来。

**三、追问一句：这个强化版，你有能力在文章里论证清楚吗？** 答不确定，说明论点还要调，或者素材还要补。

## 第二关：搭骨架

用户已有大纲或分论点，直接进第三关。没有的话二选一：

**知道大致想说什么 → SCQA**

- **S 情境**：目标读者普遍认可或正在经历的现状。必须是不具争议的客观事实起点，一到两句。
- **C 冲突**：这个现状里正在发生的变化，或被大多数人忽视的矛盾。这是推动文章往下走的驱动力，一到两句。没有冲突，读者没有理由继续读。
- **Q 疑问**：面对这个冲突，读者脑海中自然浮现的最核心问题。用读者的口吻写，一句话。
- **A 解答**：核心论点，必须是对 Q 的直接回答。"我们应该重视这件事"不是回答，是姿态；A 答不了 Q，说明论点还没想清楚。

骨架搭完立刻做一次压力测试，两条各给"够用 / 需要调整"，要调的说清具体怎么改：S 描述的情境读者会不会认同，还是只有创作者自己在意？C 提出的冲突够不够让读者觉得"这是我没意识到的问题"，还是"这个我早就知道了"？

**只有一个论点、连方向都没有 → 一问一答建逻辑**

首问固定，必须把当前强化后的论点完整放进【论点】位置，不得用"这篇文章""这个观点"代替：「你说【论点】，你认为什么样的读者最应该看这篇文章，他们现在面临的最具体的处境是什么？」这一轮只输出替换完成后的这一句首问：不提供候选读者，不替用户预设答案，不把它改成选择题或拆成分步要求。

之后根据用户的回答决定下一问，方向是逐步逼出这个观点的底层假设、关键前提、可能的薄弱环节。用户的回答出现逻辑跳跃就当场指出，再继续追问。

五到七问之后收口：已经想清楚的部分是什么，还没想清楚的部分是什么。

## 第三关：逻辑链条检查

论证断裂最常见的形式不是明显的错误，是跳步——从 A 跳到 C，中间的 B 被省略了，作者没注意到，读者跟不上。

对着大纲或分论点检查三条，只指出问题在哪，不替用户重写：

1. **跳步**：哪两个分论点之间的逻辑跳跃最大？从 A 到 B，中间缺了什么前提没说清楚？
2. **偷换问题**：最终论证的是最初提出的那个观点，还是不知不觉换成了一个更容易证明的相关问题？（要论证"内容创作者不用 AI 三年内失去竞争力"，写着写着变成了"AI 能提升内容创作效率"——后者容易证明，前者才是观点。混在一起，文章看起来论证充分，核心论点从未被真正证明。）
3. **反驳视角**：不同意的读者最容易在哪个分论点上找到攻击口？这个攻击口提前防住了没有？

三关过完 → 回 SKILL.md 的出口四项复核。
