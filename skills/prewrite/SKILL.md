# 动笔前的思路整理

写不出来通常不是没灵感，是在错误的阶段做了错误的事：该倒空的时候在打磨句子，该找主轴的时候在堆素材，该被质疑的时候直接动笔了。

这个流程的交付物是**地图**——判断、集群、骨架、诊断结果——不是正文。

## 三条贯穿规则

**地图。** 每一步交付地图，正文由用户自己写。用户明确说"帮我写"，才写。每走完一段，把地图交给用户，等他确认或修正后再进下一段——不要一口气从诊断跑到出口。

**一问一答。** 需要用户回答的地方，一次只问一个，等答完再问下一个。一次抛五个，用户会挑最容易的那个答，回避的空间就有了。

**判断句。** 所有集群标题、论点、主旨，都用完整的判断句：有人会反对，才算判断句。归类的本能是贴标签，判断句逼你从素材里提炼洞察。

| ✗ 名词词组 / 客观描述 | ✓ 判断句 |
|---|---|
| 用户行为变化 | 用户正在用碎片化时间替代深度学习 |
| 用户需要便捷性 | 用户愿意为省时间付出更高价格 |
| AI 正在改变内容创作行业 | 内容创作者不学会用 AI，三年内将失去价格竞争力 |

## 第一步：诊断卡在哪

两问定位，**先判定，再提问**：用户开场白里已经能看出答案的那一问，直接判定走哪条，不要再问一遍浪费一轮。只有判不出来的那一问才向用户提出，一次只问一个。

**第一问：手里有没有素材——笔记、资料、案例、随手记下的碎片？**

没有 → [**A 倒空**](A.md)。手上是空的，先把素材造出来。

**第二问（有素材才问）：这篇文章要说什么，用一句话说得出来吗？**

先从开场白里找信号判定，找不到信号才问用户。

| 开场白里的信号 | 走哪条 | 为什么 |
|---|---|---|
| 说"不知道要写什么""找不到主线"，或只丢过来一堆素材 | [**B / KJ 聚类**](B.md) | 还不知道素材之间是什么关系，先找内在逻辑模式 |
| 给了一句，但里面塞了两三件事 | [**B / 四层蒸馏**](B.md) | 大概知道方向，但素材太重，要压到只剩一句 |
| 给了一句明确的判断句（有人会反对） | [**C 过三关**](C.md) | 论点有了，缺的是骨架和论证 |
| 论点和分论点大纲都已经有了，明确要的是动笔前最后过一遍 | 下方**出口四项复核** | 三关的活自己做完了，直接进最后一道关；哪项不过关，复核会把他退回对应的关 |

## 出口：动笔前四项复核

三关过完走这里；用户带着论点和完整大纲直接要求动笔前复核，也从这里进。四项全部为"可以"才算完。每项从判断词开头写起：先写**可以**或**需要调整**，再写理由和一句具体的改进方向。判断词写在每一项的开头，不要挪到结尾的总结里。

拿不准的、想说"基本可以但…""偏弱，值得想一下"的，一律算"需要调整"：这是一道二值的关，给中间态等于没判。

1. 这个观点对目标读者够不够有冲击力？他们看完第一段，会不会觉得"这说的是我的问题"？
2. 论证框架能不能支撑这个观点？有没有分论点在**偷换问题**——看起来在支撑，实际论证的是另一件事？
3. 读者能不能带走一个具体的东西——一个判断、一个方法、或者一个重新理解某件事的角度？还是读完就算了？
4. 有没有哪个地方需要承认"这件事我还没有足够的证据"？打算怎么处理——补充素材，还是收窄论点范围？

判成"需要调整"的项，回对应的关重走：观点不够有冲击力回第一关，框架撑不住回第二关重搭，框架撑得住但有缺口回第三关重查，证据不够就补素材或收窄论点范围。重走完再过一遍这四项。

第 4 项最容易被跳过，因为承认证据不足感觉像在削弱自己。反过来看：动笔前就知道哪里不扎实，写的时候可以主动说明"这里还有争议"，比写完被读者指出来好得多。主动说出局限，反而让文章更可信。

四项全部"可以"，用户去写。
