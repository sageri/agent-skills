# B：素材过载，找主轴

素材多到一定程度比一无所有更难动笔——你要从里面挑，但不知道标准是什么。这时大脑的本能是继续找更多素材，这个本能是错的：信息量够了，缺的是降维。

按第二问的回答走其中一个：说不出一句话 → KJ 聚类；说得出但塞了两三件事 → 四层蒸馏。

## KJ 聚类

自下而上：先摆出所有素材，看它们自己聚成什么。不要先在脑子里设几个类别再往里塞——强行分类会漏掉真正有洞见的部分。

1. 归成 3-5 个集群，每个集群标题是判断句。
2. 指出两个盲区：哪个方向的证据明显不足？哪两个集群之间可能存在逻辑矛盾？说矛盾时必须按编号或完整标题点名上一步已经列出的两个集群，不能换成没有对应关系的新概括。
3. 把结果交给用户，请他确认两件事：哪个集群让他第一反应是"对，就是这个"（那多半是真正的核心）；两个盲区认不认同——认同的那个动笔前必须补上证据，不认同就说清为什么。
4. 从集群提 3 个候选论点，每个注明——最有力的支撑来自哪个集群、最大的反驳是什么。推荐一个论证空间最大的，说明理由。

出口：用户选定的那个论点 → 转 [C](C.md)。

## 四层蒸馏

层与层之间要有明显的压缩感。

1. **去噪**：剔除无实质内容的过渡和废话，只留含真实洞察或具体数据的 20%。
2. **重组**：压成 3-5 个逻辑严密的要点块，每块一个判断句标题。
3. **压缩**：再压成一句核心主旨，必须有观点性，允许带一定争议。
4. **延展**：给三个不同的切入角度，各一句话说清怎么切入。比如从数据反差切入、从具体失败案例切入、从读者最常见的误解切入。

第三层是关键——那句话一直在，只是被素材盖住了。

选哪个切入角度，按三条判断：读者会不会觉得"这说的是我"、有没有反直觉的成分、能不能让读者有紧迫感。推荐时必须把**读者相关性、反直觉、紧迫感**三项逐条判断清楚，不能只给一个笼统的综合理由。推荐一个，说明理由，并用它给一个不超过 50 字的开头方向——思路描述，不是写出来的正文。

出口：一句核心论点 + 一个切入角度 → 转 [C](C.md)。
